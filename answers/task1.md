# Task 1：从 C 源码到可执行文件

一个 C 程序从 `.c` 到可执行文件，大致经历四个阶段：

1. **预处理（Preprocessing）**：处理以 `#` 开头的指令，把 `#include` 的头文件内容展开进来、替换宏定义、处理条件编译，生成扩展名为 `.i` 的文本文件（`gcc -E hello.c -o hello.i`）。
2. **编译（Compilation）**：把预处理后的 C 代码翻译成汇编代码，生成 `.s` 文件，同时做大量的语法、类型等检查（`gcc -S hello.i -o hello.s`）。很多“编译错误”就发生在这一步。
3. **汇编（Assembling）**：把汇编代码翻译成机器指令，生成二进制的目标文件 `.o`（`gcc -c hello.s -o hello.o`）。
4. **链接（Linking）**：把多个 `.o` 目标文件和用到的库组合在一起，解析函数调用等符号引用，最终生成可以直接运行的可执行文件（`gcc hello.o -o hello`）。

所以「编译失败」和「链接失败」是两个不同的阶段：前者通常是语法/类型问题，后者通常是符号找不到、重复定义等。
